# رِواق — Riwaq 0.37.1

عميل Windows x64 لمنظومة إضافات **Stremio**، بواجهة عربية RTL ومشغل **MPV مدمج داخل نافذة التطبيق**، مع محرّك مصادر يشرح قراراته، وبثّ مباشر بدليل برامج، وملفات شخصية بحماية أبوية.

## قيد المراجعة بعد 0.34.0 — مشغّل الأغاني داخل رِواق

غرفة «موسيقى» أصبحت في شريط التنقل الرئيسي. أضف ملفاتك الصوتية واستمع داخل رِواق وأنت تتصفح الأفلام والمسلسلات، مع شريط تشغيل ثابت: إيقاف واستئناف، السابق والتالي، البحث داخل المقطع، مستوى الصوت، تشغيل عشوائي دون تكرار حتى انتهاء الدور، وتكرار أغنية أو القائمة.

- مكتبة قابلة للبحث بالعربية، مفضلة، قائمة انتظار قابلة للترتيب، وقوائم تشغيل محفوظة لكل ملف شخصي.
- اختيار ملفات MP3 وFLAC وWAV وOGG وOPUS وM4A وAAC من الجهاز؛ الأسماء من أسماء الملفات حالياً. ملفات الخدمات المحمية لا تتحول إلى ملفات قابلة للتشغيل هنا.
- حتى 1000 ملف في المكتبة، و200 في عملية إضافة واحدة، و40 قائمة محفوظة، و500 أغنية في قائمة التشغيل. الملف الأصلي يبقى في مكانه؛ الحذف من المكتبة لا يحذفه من القرص.
- يتوقف الصوت عند بدء الفيديو أو تبديل الملف أو قفله. تشغيل Spotify من رِواق يوقف المشغّل المحلي؛ بدء الأغاني أو استئنافها يتحقق من حالة Spotify المتصل ويوقفه أولاً عند الحاجة. مقاطع أغاني الأعمال لا تبدأ فوق الأغاني المحلية.
- تُحفظ المكتبة والانتظار والقوائم في التخزين المشفر على هذا الجهاز؛ لا تُرفع الملفات ولا تنتقل مساراتها ضمن النسخة الاحتياطية العامة. إعادة فتح التطبيق لا تبدأ الصوت تلقائياً. العشوائية والتكرار ومستوى الصوت تخص جلسة التشغيل الحالية.
- أُصلح سباق في ربط Spotify: رد متأخر بعد فصل الحساب أو تبديله لا يعيد بياناته، ولا يفسد ربطاً جديداً. كما أُصلح تداخل طلبات الشريط وحالة الجهاز الغائبة.

هذه تغييرات مصدر في طلب مراجعة، وليست مثبتاً جديداً. تحكّم Spotify والقوائم والروابط السابقة باقية؛ الصوت من Spotify يظل عبر Spotify Connect. [مراجعة التحديثات وخطة المنصة الترفيهية](docs/REVIEW-2026-10-05.md) · [الاختبارات والحدود](VERIFICATION.md).

## بوصلة ذوقك — منذ 0.31.0

اقتراحات محلية في الرئيسية و«اكتشف»، تتأثر بالأنواع التي تختارها و«أحببته» في صفحة العمل أو بطاقة الاقتراح. كل بطاقة تشرح سبب ظهورها. اختر «قريب من ذوقي» أو «توازن» أو «وسّع عالمي»، وصفِّ الأفلام حسب الوقت المتاح.

- «لا تقترحه» يستبعد العمل من البوصلة وجلسة رِواق؛ يبقى في البحث والمكتبة. يمكنك مراجعة الآراء والتراجع عنها أو تصفير الذوق بتأكيد.
- جلسة رِواق تراعي ذوقك عند المفاضلة، مع استمرار حدود الوقت والاستراحات.
- كل ملف شخصي له اختياراته، تُحفظ محلياً وتنتقل مع النسخة الاحتياطية المشفرة. لا تحتاج مفتاح ذكاء اصطناعي ولا تُرسل الآراء إلى تراكت أو أي منصة.
- تعمل البوصلة على عينة من الأعمال المحمّلة، وتستبعد الأفلام المكتملة والعناوين القادمة. لا تدّعي نسبة توافق ولا تضمن وجود مصدر تشغيل.

دخلت البوصلة الإصدار 0.31.0. [المراجعة الأصلية وخطة التطوير](docs/REVIEW-2026-10-03.md) · [التحقق وحدوده](VERIFICATION.md).

## جلسة رِواق والواجهة الجديدة — منذ 0.27.0

**جلسة رِواق** تجعل البداية اختيار تجربة تناسب وقتك: حدّد 30 أو 60 أو 90 أو 120 أو 180 دقيقة، واختر مزاجك. يرتّب رِواق حتى ثلاثة أعمال من مكتبتك ومتابعتك وفهارسك المحمّلة، ويحسب المتبقي مما بدأت مشاهدته، مع خمس دقائق استراحة بين الأعمال. لكل اختيار سبب ظاهر وزر بديل، ويمكن فتح العمل الأول أو إضافة الجلسة إلى طابور المشاهدة.

- **تنقّل جديد:** أربع وجهات أفقية — جلسة اليوم، اكتشف، مكتبتي، مجموعاتي — وبطاقة أدوات للبث والإضافات وحساب ستريميو.
- **إعدادات أوضح:** ست بطاقات للأقسام، ثم تبويبات الخيارات والبحث، مع استمرار التخصيص والألوان والشعار.
- **من دون مفتاح ذكاء اصطناعي:** التخطيط محلي، ويجلب مدد الأعمال عبر إضافاتك. لا يفترض مدة للعمل إذا غابت بياناتها؛ ومدد حلقات المسلسلات قد تكون تقديرية.
- يُحفظ الوقت والمزاج لكل ملف شخصي. للعودة: **الإعدادات ← المظهر ← الواجهة ← تجربة رِواق ← التخطيط السابق**.

نُشرت الواجهة والجلسات مع 0.27.0. [طريقة الجلسات وحدودها](docs/RIWAQ-SESSIONS.md) · [ما اختُبر](VERIFICATION.md).

## الجديد في 0.37.1 — الصورة ترجع لو اختفت، وHDR بثلاث طرق

- **وش تعلمنا من هاربور:** في سلسلة دعم هاربور، HDR الحقيقي داخل نافذة مضمّنة ما يعامله ويندوز كنافذة HDR، فهاربور فصله في نافذة MPV منفصلة بلا أزرار. وأكبر شكوى عندهم: ما فيه أدوات تحكم ولا طريقة ترجع للتطبيق.
- **طرق HDR الثلاث** (الإعدادات ← جودة الفيديو ← HDR):
  - **تحويل إلى SDR** (الافتراضي): صورة دقيقة على أي شاشة، مع كل أدوات التحكم.
  - **HDR حقيقي · نافذة منفصلة:** لمصادر HDR فقط. MPV يفتح بملء الشاشة في نافذته، وفيها أدوات تحكم MPV نفسه (حرّك الفأرة)، وEsc يرجعك لرِواق، والنقر المزدوج يكبّر ويصغّر. المصادر العادية تبقى داخل رِواق.
  - **HDR حقيقي · مضمّن (تجريبي):** داخل رِواق مع كل الأدوات، لكن على بعض الأجهزة تختفي الصورة.
- **مفتاح «إشارة HDR» القديم** ما عاد يفرض HDR حقيقي، فمن كان مشغّله رجع إلى التحويل إلى SDR.

- **البلاغ:** بعد 0.37.0 اشتغل الصوت والصورة ما ظهرت (حلقة 4K HDR10). الإعدادات الافتراضية للصورة ما تغيّرت، لكن نسخة MPV المرفقة تغيّرت إلى v0.41، لأن النسخة السابقة حُذفت من مصدرها.
- **شبكة أمان:**
  - إذا عند الملف مسار فيديو وMPV ما جهّز مخرج الصورة خلال ست ثوانٍ، رِواق يعيد التشغيل من نفس اللحظة بوضع التوافق، ويقول لك.
  - وضع التوافق: العارض الأقدم (gpu)، وفك الترميز بالمعالج، وبدون خيارات الصورة الاختيارية مثل RTX وHDR والوضعين الآخرين. خيارات الصوت تبقى.
  - يحاول مرة واحدة لكل مشاهدة. وإذا ما نفع، يطلب منك «تشخيص كامل».
- **سجل MPV:** كل مشاهدة تكتب سجل MPV في مجلد بيانات رِواق. «تشخيص كامل» يعرض منه سطور الأخطاء فقط، بعد إزالة الروابط (يبقى اسم الموقع) والمفاتيح وسطر الأوامر وترويسات HTTP.

أول تقرير من جهاز حقيقي (ويندوز 11، 57 إضافة) كشف ثلاثة إنذارات خاطئة ومشكلتين حقيقيتين:

- **فحص الإضافات في صفحة الإضافات:** زر «افحص الإضافات» يعطي كل إضافة شارة: تعمل، بطيئة (أكثر من 3 ثوانٍ)، توقفت نهائياً (404)، لا تستجيب الآن، تحتاج Stremio Service، أو مكررة.
  - «احذف المتوقفة» يحذفها كلها بضغطتين للتأكيد.
  - «عطّل اللي ما تستجيب» يوقفها لين ترجع.
  - الفحص يتم في التطبيق، والروابط ما تطلع للواجهة.
- **تشخيص أدق:**
  - سطح الفيديو المخفي وقت عدم المشاهدة ما عاد يُحسب تنبيهاً، لأن القص يُضبط عند ظهوره.
  - Trakt ينفحص بـ Client ID حقك. بدونه، رد 403 يعني «متاح ويحتاج مفتاح» مو حجب.
  - الإضافة المحلية (مثل Local Files) تنعرض كـ«تحتاج Stremio Service» بدل «معطلة».
  - الإضافات المثبتة مرتين تنعرض «مكررة».
  - عنوان Stremio Service المحلي يحتفظ برقم المنفذ في التقرير.

## الجديد في 0.28.0 — «اكتشف» بتصنيف رِواق

- **أقسام رِواق بدل أقسام الإضافات:** الصفحة صارت تبويبات: أفلام، مسلسلات، عربي، حول العالم، أنمي، للعائلة، وثائقي. وكل قسم صفوف بتصنيف رِواق:
  - أفلام: رائجة هذا الأسبوع، الأكثر شعبية، صدرت حديثاً، الأعلى تقييماً، أكشن، كوميديا، دراما، إثارة، رعب، خيال علمي، رومانسي، تاريخ وحروب، كلاسيكيات.
  - عربي: مسلسلات عربية جديدة، دراما خليجية ومصرية وشامية، أفلام عربية، وأفضلها تقييماً.
  - حول العالم: تركي، كوري، هندي، إسباني ولاتيني، ياباني، فرنسي.
  - أنمي وعائلة ووثائقي: شائع وجديد وأعلى تقييماً.
- **ولا إضافة تُذكر:** كتالوجات إضافاتك ما تختفي، تنضم للقسم اللي تنتمي له أعمالها في صف واحد «مختارات أخرى» لكل نوع، بدون اسم كتالوج ولا إضافة، وبدون تكرار أعمال موجودة في صفوف رِواق. حتى رسالة التعذّر صارت «بعض الأعمال لم تصل بعد» بدل أسماء الإضافات. والأقسام اللي تملؤها الإضافات بس (رياضة، قنوات، يوتيوب) تظهر تبويباً لما يكون عندك منها.
- **بمفتاح TMDB أو بدونه:** بالمفتاح تجي الصفوف من TMDB بلغة الواجهة ومنطقتك. بدونه تجي أقسام الأفلام والمسلسلات والعائلة والوثائقي من Cinemeta حسب النوع، وأقسام العربي وحول العالم والأنمي تقول لك إنها تكتمل بالمفتاح.
- **«عرض الكل»** في أي صف يفتح صفحته الكاملة مع «تحميل المزيد».

## الجديد في 0.27.0 — الحلقة التالية جاهزة، وتخطٍّ على ذوقك

- **الحلقة التالية بلا انتظار:** مع «متابعة المشاهدة تلقائياً»، لما يتبقى من الحلقة أربع دقائق (أو تتجاوز 90% منها)، يسأل رِواق إضافاتك عن مصادر الحلقة التالية في الخلفية، أو عن أول عنوان في الطابور إن وُجد. لما تخلص الحلقة يبدأ التالي مباشرة بدل ما ينتظر كل الإضافات من جديد. ما يُحمّل أي فيديو مسبقاً: الطلب للمصادر فقط، ويُستخدم الجواب لنفس العنوان ونفس الملف الشخصي خلال عشر دقائق. ولو ما فيه مصدر قابل للتشغيل في الجواب المبكر، يعيد السؤال.
- **إيقاف التخطي التلقائي لمسلسل واحد:** لو مفعّل «تخطٍّ تلقائي» للمقدمة أو الخاتمة، تلقى في صفحة المسلسل خيار «تخطٍّ تلقائي للمقدمة هنا». أطفئه لمسلسل تحب مقدمته، ويظهر فيه زر التخطي بدل التخطي التلقائي. والتغيير يطبّق فوراً حتى أثناء المشاهدة. في إعدادات المشغل تشوف عدد المسلسلات المستثناة وزر «أعد التخطي للكل».

## الجديد في 0.26.0 — ذاكرة المسلسل وخطوة تقديم موحّدة

- **نفس المصدر في الحلقة التالية:** لما تشغّل حلقة، يحفظ رِواق الإضافة وفريق الإصدار والجودة (بدون الرابط). في الحلقة التالية يقدّم المصدر المطابق أول القائمة بشارة «مصدرك السابق» وسبب واضح «نفس مصدر الحلقة السابقة». فالتشغيل التلقائي للحلقة التالية يكمل بنفس النسخة، ولا تقفز الجودة أو الترجمة بين الحلقات. والمرشّح المفعّل يبقى له الأولوية: المصدر المحفوظ يتقدّم داخل المطابق فقط.
- **نفس الصوت والترجمة:** لو اخترت في المسلسل صوتاً يابانياً وترجمة عربية، أو أطفأت الترجمة، يرجع اختيارك في الحلقة التالية. المطابقة باللغة والعنوان ونوع الترجمة، مو برقم المسار اللي يتغير بين الملفات. والترجمة الإجبارية ما تحل محل الكاملة. ولو كانت ترجمتك من إضافة، يطلبها رِواق من الإضافات بنفس اللغة.
- **التحكم بيدك:** خيار «تذكّر اختياراتك لكل مسلسل» في إعدادات المشغل (مفعّل افتراضياً)، و«انسَ الكل»، و«انسَ اختياري» تحت المصادر في صفحة المسلسل. الذاكرة لكل ملف شخصي وحده، وحدّها 200 مسلسل.
- **خطوة تقديم موحّدة:** الأسهم في MPV كانت ثابتة على 10 و60 ثانية مهما اخترت. صارت تقرأ إعدادك لحظة الضغط، مثل أزرار الشاشة والواجهة. وأضفنا خطوة 15 ثانية، وخطوة طويلة (Shift مع الأسهم) تختارها: 30 ثانية إلى 5 دقائق.
- **ترجمة متأخرة ما تخرب المشاهدة:** لو بدّلت المصدر وإضافة الترجمة لسه ما ردّت، كان ممكن تنضاف ترجمة النسخة السابقة. صار رِواق يتأكد إن الرد للمشاهدة الحالية نفسها قبل ما يطبّقه.

## الجديد في 0.25.1 — إصلاح الربط مع تراكت

- **سبب المشكلة:** تراكت صار خلف Cloudflare، ويرفض (403) أي طلب ما يذكر اسم التطبيق في ترويسة User-Agent. رِواق ما كان يرسلها، فكانت تفشل كل الطلبات: الربط والمزامنة وتسجيل المشاهدة والاقتراحات. والخطأ الإنجليزي «HTTP 403» كان يتحول لرسالة عامة («تعذّر إكمال العملية…») تخفي السبب.
- **الإصلاح:**
  - كل طلب لتراكت (وSimkl) صار يرسل `Riwaq/الإصدار` في User-Agent.
  - صفحة إدخال الرمز صارت الصفحة اللي يرسلها تراكت نفسه (`trakt.tv/activate`).
  - رابط «إعدادات الخدمة» يفتح صفحة تطبيقاتك في تراكت (`trakt.tv/oauth/applications`).
- **رسائل واضحة بالعربي:** بدل الرسالة العامة، تقول الرسالة السبب وش تسوي:
  - رفض بيانات التطبيق: تحقق من Client ID وClient Secret.
  - انتهت الجلسة: أعد الربط.
  - طلبات كثيرة: انتظر دقيقة.
  - الحساب مقفل، أو خوادم تراكت لا تستجيب.
  - وخلال الربط: الرمز انتهى أو استُخدم، أو رُفض الربط.
  - وأي خدمة ثانية ترد برمز خطأ، يظهر رمزها في الرسالة بدل الجملة العامة.
- **خطوات إعداد تراكت في بطاقة الربط:** أنشئ تطبيقاً، اكتب في Redirect URI `urn:ietf:wg:oauth:2.0:oob`، ثم انسخ Client ID وClient Secret.

## الجديد في 0.25.0 — الرئيسية بتصنيف رِواق، لا بالإضافات

- **الرئيسية صارت تعرض الأعمال بتصنيف رِواق الخاص** بدل صف لكل كتالوج من كل إضافة. مهما كثرت إضافاتك، الرئيسية تبقى مرتبة.
  - **مع مفتاح TMDB** (بلغتك ومنطقتك)، الصفوف هي: رائج هذا الأسبوع، في السينما الآن، مسلسلات رائجة، مسلسلات عربية، أفلام شائعة، تُعرض حلقاتها الآن، أفلام عربية، الأعلى تقييماً (أفلام ومسلسلات)، مسلسلات تركية، دراما كورية، أنمي، أكشن ومغامرة، كوميديا، خيال علمي وفانتازيا، رعب، جريمة وغموض، للعائلة والصغار، وثائقيات، جواهر قد تكون فاتتك، قريباً في السينما.
  - **بدون مفتاح** تجي الصفوف من Cinemeta: الأكثر مشاهدة الآن، مسلسلات يتابعها الجميع، وأنواع الأفلام والمسلسلات (أكشن، دراما، كوميديا، خيال علمي، إثارة، جريمة، رسوم متحركة، رعب، رومانسي، مغامرة، فانتازيا، غموض، وثائقيات). Cinemeta ما يعرف اللغات، فصفوف العربي والتركي والكوري تحتاج المفتاح.
  - **تحت صفوف رِواق** رفوف من إضافاتك للي ما يغطيه التصنيف: مقترحة لك، عربي (أكوام، وي سيما…)، قنوات وبث مباشر، رياضة، يوتيوب، وأنمي إذا ما عندك مفتاح. فوق كل رف أزرار لكتالوجاته، و«الكل» يخلط بينها.
  - الواجهة الكبيرة فوق تاخذ أعمالها من صفوف رِواق، وكل صف له «عرض الكل» مع «تحميل المزيد».
  - إضافاتك تبقى في «اكتشف»، وهي اللي تجيب المصادر لما تضغط تشغيل.
- **من «الإعدادات ← الصفحة الرئيسية ← ترتيب الرئيسية»:**
  - تصنيف رِواق حتى أسوي مجموعاتي (الافتراضي).
  - تصنيف رِواق دائماً.
  - كتالوجات إضافاتي في أقسام.
  - كل كتالوج في صف (الطريقة القديمة).
  - وتقدر تخفي أي صف من صفوف رِواق أو أي رف من رفوف إضافاتك.
- **قسم «مقترحة لك من تراكت»:** يجيب من حسابك في تراكت اقتراحات أفلام ومسلسلات حسب ما تشاهده وتقيّمه هناك.
  - زر للأفلام وزر للمسلسلات، وزر «تحديث» لاقتراحات جديدة.
  - على كل بطاقة زر «مو مهتم» يخلّي تراكت يوقف اقتراح العمل لحسابك.
  - إذا ما ربطت تراكت، يطلع لك زر «اربط تراكت» يوديك للإعدادات.
  - القسم يظهر تحت «الحلقات التالية»، حتى لو كنت مرتّب أقسام الرئيسية من قبل، وتقدر تخفيه من «أقسام الرئيسية».
  - الاقتراحات قراءة فقط: ما يُرسل لتراكت شي إلا لما تضغط «مو مهتم».
- **«اكتشف» بأقسام بدل أنواع الإضافات:** بدل عشرين زراً بأسماء الإضافات (arabcity-akwam، wecima، youtube…)، صارت الأزرار أقساماً، وجنب كل قسم عدد كتالوجاته:
  - مقترحة لك، أفلام، مسلسلات، عربي، أنمي، قنوات، رياضة، يوتيوب، أخرى.
  - قوائم مثل DC وMarvel تنحسب حسب أغلب أعمالها.

## التنزيل

نزّل أحدث نسخة من [صفحة الإصدارات](https://github.com/ABADIOSA/riwaq/releases). اختر ملف **Riwaq-Setup-0.37.1-win-x64.exe** للتثبيت وتفعيل التحديثات الداخلية، أو النسخة المحمولة للاستخدام اليدوي. كلاهما يتضمن Node.js وMPV. يُبنى كل إصدار على ويندوز عبر GitHub Actions، ويُرفق معه ملف `SHA256SUMS.txt` ببصمة الملف.

تحقّق من الملف قبل تشغيله بمقارنة بصمته:

```powershell
Get-FileHash .\Riwaq-Setup-0.37.1-win-x64.exe -Algorithm SHA256
```

> [!WARNING]
> الملف **غير موقَّع** بشهادة نشر ويندوز، وقد يظهر تنبيه SmartScreen. تعليمات بناء نسخة من المصدر في [التطوير والبناء](#التطوير-والبناء).

## البدء

1. افتح **حساب ستريميو** وسجّل الدخول عبر صفحة ستريميو الرسمية في المتصفح.
2. يعود رِواق ليستورد إضافاتك المهيأة والمكتبة ومواضع المشاهدة. يمكن إضافة روابط manifest.json يدويًا أيضًا.
3. اختر عنوانًا، ثم الحلقة والمصدر. الفيديو يعمل داخل رِواق؛ زر التصغير يبقيه في مشغل مصغّر أثناء التصفح.
4. من **الإعدادات ← مكتبة البيانات** أضف مفاتيح خدماتك، ثم اختبر الاتصال.
5. من **الحسابات والربط** اربط المنصات؛ تظهر قوائم Trakt وSimkl في مكتبتي، وLetterboxd عبر كتالوجات الإضافة.
6. من **بث مباشر** أضف قائمة M3U أو اشتراك Xtream تملكه؛ يُقرأ دليل البرامج تلقائياً إن وفّره المزوّد.

لا تضع كلمات المرور أو مفاتيح API في المحادثات أو ملفات المصدر. بيانات رِواق الشخصية محفوظة مشفرة تحت `%APPDATA%/Riwaq/profile.bin`.

### استخدام طابور المشاهدة

1. افتح تفاصيل الفيلم أو المسلسل، واختر الحلقة إن وجدت، ثم اضغط **أضف إلى الطابور**.
2. افتح **مكتبتي** ثم **طابور المشاهدة** لترتيب العناصر بالسهمين أو إزالتها. افتح العنصر لاختيار مصدره وتشغيله.
3. للانتقال تلقائيًا عند انتهاء الفيديو، افتح **الإعدادات** ثم **المشغل والمصادر** وفعّل **متابعة المشاهدة تلقائياً**. يستخدم التطبيق أول مصدر متوافق وفق إعداداتك، ويعطي الطابور الأولوية على الحلقة التالية.

### النسخ الاحتياطي والانتقال لجهاز جديد

1. افتح **الإعدادات ← النسخ الاحتياطي**، واكتب عبارة مرور من 8 أحرف على الأقل مرتين، ثم **حفظ نسخة احتياطية**.
2. احتفظ بالملف `.riwaq` وبعبارة المرور. **لا نستطيع فتح النسخة إن نسيت العبارة.**
3. على الجهاز الجديد افتح القسم نفسه، واختر الملف، واكتب العبارة، وراجع المعاينة ثم **استعادة الآن**.

النسخة العادية لا تحمل الأسرار: روابط الإضافات المهيأة (فيها مفاتيحها غالباً)، وتسجيل دخول ستريميو، ومفاتيح الخدمات، وحسابات المنصات، واشتراكات القنوات، ووجهات الإشعارات. يخبرك رِواق بما تُرك منها لتعيد إضافته. ضع علامة **تضمين مفاتيحي وحساباتي** لنقل كل شيء — حينها أمان النسخة بقدر عبارة المرور وحدها.

الاستعادة تستبدل الملفات الشخصية ومكتباتها وإعداداتها. المفاتيح التي لا تحملها النسخة تبقى كما هي على هذا الجهاز، ويُحفظ ملفك الحالي بجانبها باسم `profile.before-restore.bin` للتراجع على هذا الجهاز. إن قفلت قسم **الإعدادات** برمز الحماية، فالنسخ والاستعادة يتطلبان الرمز أيضاً.

### الحلقات التالية والتقويم

- تظهر **الحلقات التالية** في الرئيسية للمسلسلات المحفوظة في مكتبتك أو في طابورك أو التي شاهدت منها حلقة. المسلسل الذي تشاهد حلقته الآن يبقى في «نكمل الحكاية؟».
- **مكتبتي ← التقويم** يعرض حلقات هذه المسلسلات للأسبوع الماضي والشهر القادم.
- إن تابعت مسلسلاً في تطبيق آخر، افتح الحلقة التي وصلت إليها واضغط **شاهدت كل ما قبلها** لتبدأ الحلقات التالية من هناك.

### Trakt لحظياً

بعد ربط Trakt وتفعيل **تسجيل المشاهدة في Trakt** من **الحسابات والربط**، فعّل **تسجيل لحظي (Scrobble)**. عند الإيقاف قبل 80% يحفظ Trakt موضعك فقط؛ بعد 80% تُسجَّل المشاهدة. إن انقطع الاتصال لحظة الإيقاف تُحفظ المشاهدة في طابور الإرسال وتُرسل لاحقاً.

## الميزات المتوفرة

ميزات 0.3 محفوظة في هذا الإصدار، بما فيها محرّك المصادر والبث المباشر والملفات الشخصية وأدوات المشغل.

### محرّك المصادر — يشرح لماذا رتّب كما رتّب

مسار من أربع مراحل: قراءة، ثم استبعاد، ثم تقييم، ثم تصنيف إلى طبقات.

- **قراءة**: الدقة، ونوع HDR (DV، HDR10+، HDR10، HLG)، ومرمّز الفيديو وعمق البت، ونوع النسخة (REMUX، BluRay، WEB-DL…)، والصوت وعدد قنواته، والحجم وعدد المصادر، وفريق الإصدار، والنسخة الخاصة، والموسم والحلقة، وحالة التخزين على debrid، واللغات من الكلمات ومن أعلام الدول.
- **استبعاد**: العيّنات والمقاطع الدعائية والمواد الإضافية، والأوصاف التي تحمل روابط ودعاية، والنسخ المضخّمة صناعياً، وتصوير الصالة، والحلقة أو الموسم الخطأ، والملفات الأصغر من أن تطابق وصفها، والتورنت بلا مصادر. ولك ثلاثة مستويات: صارم ومتوازن ومطفأ، مع حدّ اختياري لحجم الملف.
- **تقييم وتصنيف**: كل نقطة مسجّلة باسمها. اضغط زر المعلومات بجانب أي مصدر لترى تفصيل نقاطه، واضغط «عرض المستبعَد» لترى ما حُذف ولماذا.
- **الأولوية العربية ليست مكافأة إضافية**: يميّز المحرّك بين «مترجم» و«مدبلج»، فالترجمة العربية تُقدَّم حين تطلبها في لغات الترجمة، والدبلجة تُقدَّم فقط حين تطلبها في لغات الصوت — ولا تُفرض على من يريد الصوت الأصلي.

### بث مباشر بدليل برامج

قوائم M3U واشتراكات Xtream Codes، مع قراءة XMLTV واختيار العنوان العربي حين يوفّره المزوّد. شبكة قنوات بالشعارات وبرنامج الآن والتالي وشريط تقدّم، وتصنيفات ومفضلة وبحث يتجاهل التشكيل واختلاف الألف والياء والتاء المربوطة، ودليل برامج بخط زمني ومؤشر «الآن»، وإعادة مشاهدة للبرامج المنتهية بأساليب default وappend وshift وflussonic وXtream.

### مشغّل أوسع

تخطي المقدمة والخاتمة من فصول الملف مع زر أو تخطٍ تلقائي، وعلامات المقاطع على شريط التقديم، وتكرار مقطع A/B، ومؤقّت نوم، والتقاط صور، وتأخير الصوت، وتكبير وإزاحة الصورة، وترجمة ثانوية، ولوحة إحصائيات، ومرشّحات صورة مبنية على محرّك MPV، وتحويل HDR إلى SDR، ومخزون وإعادة اتصال للبث المباشر، و**كل مفاتيح المشغّل قابلة لإعادة التعيين** مع كشف التعارض.

### ملفات شخصية وحماية أبوية

حتى ستة ملفات شخصية، لكل واحد مكتبته وتقدّمه وقوائمه وإعداداته. رمز حماية من 4 إلى 8 أرقام مخزّن بتجزئة scrypt بملح مستقل، وأقسام يمكن قفلها، وفتح يعيش في الذاكرة فقط فيُقفل كل شيء عند التبديل أو الإغلاق.

### حضور وإشعارات — اختيارية بالكامل

حضور Discord عبر أنبوب محلي بمعرّف تطبيق تملكه أنت، بثلاثة مستويات تفصيل. وإشعارات عبر Webhook من Discord أو بوت Telegram تملكه، مع رفض التحويلات والتحقق من المضيف الرسمي.

### الواجهة والتصفح

- سبعة ثيمات، ثلاثة تخطيطات (سينمائي، جانبي، علوي)، بطاقات زجاجية/بسيطة بأحجام مختلفة، تقليل الحركة وإخفاء المكتمل والتقييمات، وإعدادات قابلة للبحث.
- كتالوجات وبحث وتفاصيل ومواسم وحلقات ومفضلة وتقدم محلي، مع إدارة ترتيب الإضافات وتفعيلها واستيراد/تصدير روابطها.
- MPV مدمج داخل نافذة رِواق: ملء شاشة، تصغير داخل التطبيق، مسارات صوت وترجمة، ملفات SRT/ASS، أولوية لغات، حجم وتأخير الترجمة، سرعة ونسبة صورة وضبط سطوع/تباين/تشبع/جاما، تسريع عتاد وخيار HDR، واستئناف وتشغيل الحلقة التالية.

## حدود واضحة

- استيراد Stremio في اتجاه واحد إلى رِواق. التغييرات المحلية لا تُرفع لحساب ستريميو. الإضافات المحذوفة من السحابة لا تُحذف محليًا تلقائيًا.
- مصادر التورنت/infoHash تحتاج **Stremio Service** تعمل على الجهاز؛ العنوان الافتراضي `http://127.0.0.1:11470`. الخدمة غير مرفقة. مصادر HTTP/HTTPS المباشرة لا تحتاجها.
- المشغل المصغّر يبقى داخل رِواق؛ ليس نافذة PiP مستقلة فوق التطبيقات الأخرى. HDR يعتمد على المصدر والشاشة وإعدادات ويندوز، ولم يُتحقق منه على شاشة HDR فعلية أو عدة شاشات بدقات مختلفة.
- الربط مع Letterboxd عبر Stremboxd طرف ثالث معلن، وليس OAuth رسميًا. واجهة Letterboxd الرسمية تتطلب موافقة خاصة. لا نطلب كلمة مرور Letterboxd. CSV لقطة محلية لا تحدث الحساب؛ يستورد أول 500 صف مع مطابقة دقيقة للاسم والسنة، ويبلغ عن غير المتطابق والزائد.
- Trakt يحتاج Client ID وClient Secret من تطبيق المستخدم، وSimkl يحتاج Client ID. استيراد Trakt محدود حاليًا بـ1,000 عنوان لكل نوع في المزامنة. تسجيل الإكمال مغلق افتراضيًا؛ عند تفعيله ترسل الأعمال عند 90%، ويعاد إرسال المتعثر مع مزامنة القوائم التالية. Simkl حاليًا قراءة قوائم فقط.
- **رِواق لا يوفّر قنوات ولا اشتراكات ولا محتوى.** مصادر البث المباشر تأتي من قوائم يملكها المستخدم، وبيانات الاشتراك تُحفظ مشفّرة ولا تصل إلى الواجهة أبداً؛ القنوات تُعنون بمفتاح مبهم ويُترجم داخل العملية الرئيسية عند التشغيل فقط.
- تخطي المقدمة يعتمد على فصول الملف. عند غيابها يُستخدم استدلال متحفّظ ضمن نافذة المقدمة فقط، ولا يوجد تكامل مع AniSkip أو قواعد فصول خارجية.
- مرشّحات الصورة مبنية على خيارات MPV نفسها (scale وdeband وsigmoid). **لا نرفق ملفات Anime4K ولا أي شيدر من طرف ثالث**؛ من يملك سلسلة GLSL يشير إليها من الإعدادات.
- حضور Discord يحتاج معرّف تطبيق من المستخدم وتطبيق Discord يعمل على الجهاز؛ لم يُختبر مع عميل Discord حقيقي.
- الملفات الشخصية تفصل المكتبة والتقدّم والقوائم والإعدادات. الإضافات ومفاتيح الخدمات وحسابات المنصات ومصادر القنوات مشتركة بين الجميع عن قصد.
- **عبارة مرور النسخة الاحتياطية لا تُستعاد.** رِواق لا يحتفظ بها ولا يستطيع فتح نسخة بدونها.
- التقويم والحلقات التالية يعتمدان على تواريخ العرض التي تقدمها إضافاتك (Cinemeta عادة)، لأحدث 40 مسلسلاً تتابعه. الحلقة بلا تاريخ مقروء لا تظهر في التقويم، والحلقات الخاصة (الموسم 0) لا تُعد «التالية».
- Trakt اللحظي لم يُختبر مع حساب Trakt حقيقي؛ اختُبر مقابل شكل الواجهة الموثّق. يعتبر Trakt المشاهدة مكتملة عند 80% في الوضع اللحظي، و90% في وضع الإكمال.
- فحص الإصدارات يرسل طلبًا مجهولًا إلى GitHub كل أربع ساعات ويمكن إيقافه. قد يتعذر بسبب انقطاع الاتصال أو حد الطلبات؛ تظهر إعادة المحاولة داخل التطبيق. التنزيل والتثبيت يتطلبان حزمة موقّعة والنسخة المثبّتة، ولا يتطلبان حساب GitHub من المستخدم.
- الربط مع نوفيو يقرأ بيانات نوفيو المحفوظة على نفس الجهاز أو ملف نسخته الاحتياطية، ولا يتصل بحساب نوفيو على خوادمه: الخادم الرسمي يتطلب مفتاح عميل لا ينشره نوفيو في شيفرته المصدرية. إذا كنت تستخدم نوفيو على الجوال فقط، صدّر المجموعات والصقها. مصادر TMDB تحتاج مفتاح TMDB، وقوائم Trakt تحتاج Client ID من تطبيقك في Trakt، ولا يلزم تسجيل الدخول. العنوان الذي لا يجد له TMDB معرّف IMDb لا يظهر، لأن إضافاتك لا تستطيع فتحه. **رِواق لا يشغّل أدوات نوفيو البرمجية (Plugins)**: ينقل قائمة المستودعات فقط، لأنها شيفرة JavaScript من أطراف أخرى. لم يُختبر الربط على نسخة نوفيو حقيقية بعد؛ بُني على صيغة ملفات نوفيو المفتوحة المصدر.
- البحث عن الأشخاص يشمل من لهم معرّف IMDb في Wikidata فقط، و«من نفس السلسلة» يعتمد على تسجيل Wikidata للأجزاء. الإعلان يفتح في المتصفح لأن رِواق لا يرفق أداة لتشغيل يوتيوب داخل المشغّل.
- صنّاع العمل من Wikidata، وهي موسوعة يحرّرها متطوعون: بعض الأعمال ناقصة أو بلا مواقع تصوير، والأسماء بالعربية إن توفّرت وإلا بالإنجليزية. «الأعمال الأخرى» تشمل ما له معرّف IMDb فقط، ونوع العمل (فيلم/مسلسل) يُقرأ من Wikidata وقد يخطئ فيجرّب رِواق النوع الآخر. خرائط المواقع صور من OpenStreetMap.
- لا يزال غير موجود: تنزيلات، بث للأجهزة (Chromecast/DLNA/AirPlay)، Watch Party، DVR، متجر إضافات داخل التطبيق، وPiP على مستوى النظام.
- الإضافات الحديثة HTTP/HTTPS مدعومة. نقل legacy/IPFS وNZB والأرشيفات غير مدعوم؛ روابط YouTube والخارجية تفتح في المتصفح.
- اختبارات OAuth ومفاتيح الخدمات والبث المباشر والإشعارات محاكاة بعقود API ومدخلات حقيقية الشكل؛ لم تُستخدم حسابات ولا اشتراكات شخصية فعلية في التحقق. راجع [VERIFICATION.md](VERIFICATION.md) لما جرى اختباره فعلاً وما لم يجرِ.

## التطوير والبناء

المتطلبات: Windows x64 وNode.js 24 وnpm. لا تحتاج Rust أو Visual Studio؛ Koffi يستخدم ملفًا ثنائيًا جاهزًا لاستدعاءات Win32.

> [!IMPORTANT]
> **ابنِ على ويندوز.** البناء المتقاطع من Linux أو macOS يمرّ بلا خطأ لكنه ينتج ملفًا معطوبًا: يثبّت npm نسخة Koffi الخاصة بنظام البناء لا بويندوز، فيُقلع التطبيق ثم يفشل في إنشاء سطح الفيديو المدمج. سير عمل [`release.yml`](.github/workflows/release.yml) يبني على `windows-latest` لهذا السبب تحديدًا.

```powershell
npm ci
node scripts/fetch-mpv.mjs
npm test
npm run check
npm run build
npm start
npm run package
```

يتحقق سكربت MPV من SHA-256 للأرشيف المثبت الإصدار. المنتج في `release/`. أغلق أي نسخة قيد التشغيل قبل إعادة الحزم.

لإصدار نسخة جديدة: اضبط سر التوقيع `RIWAQ_UPDATE_PRIVATE_KEY` مرة واحدة، ثم ادفع وسمًا يطابق إصدار الحزمة مثل `v0.8.0`. يبني سير العمل المثبت والنسخة المحمولة ويوقّع بيانات التحديث وينشر الملفات بعد اكتمالها. يمكن اختيار القناة المستقرة عند تشغيل سير العمل يدويًا. اتبع [دليل التحديثات](docs/UPDATES.md).

اختبار فعلي من المصدر بملف شخصي جديد ومعزول:

```powershell
$env:RIWAQ_DATA_DIR = Join-Path (Get-Location) '.cache/smoke-profile-new'
$env:RIWAQ_SMOKE = '1'
npm start
```

اختبار النسخة المحمولة:

```powershell
node scripts/test-packaged.mjs release/Riwaq-0.37.1-win-x64.exe
```

لا تستخدم RIWAQ_SMOKE مع ملفك الشخصي الحقيقي؛ يضيف بيانات اختبار. اختبار المصدر يستخدم كتالوج Cinemeta الحقيقي ومصدر فيديو محليًا اصطناعيًا. CI يفحص المصدر والبناء دون GPU؛ الاختبار الأصلي يحتاج جلسة سطح مكتب ويندوز.
