# رِواق — Riwaq 0.12.2

عميل Windows x64 لمنظومة إضافات **Stremio**، بواجهة عربية RTL ومشغل **MPV مدمج داخل نافذة التطبيق**. تنفيذ أصلي، دُرست فيه سلوكيات Harbor وNuvio Desktop وStremio Community v5، مع محرّك مصادر يشرح قراراته، وبثّ مباشر بدليل برامج، وملفات شخصية بحماية أبوية.

تحديث **0.12.2** يجعل كل مصدر في المجلد يقول سبب فراغه إن كان فارغاً، ويحمي مصادر TMDB من حدّ الطلبات، ويُظهر عناوين TMDB بلا معرّف IMDb عبر إضافة تفتح معرّفات TMDB. تحديث **0.12.1** أظهر محتوى مجلدات نوفيو المبنية على TMDB وTrakt، وكانت تنتقل فارغة. تحديث **0.12.0** أضاف **المجموعات** لترتيب الأفلام والمسلسلات على ذوقك، و**الربط مع نوفيو** لنقل الإضافات والمجموعات والمكتبة ومستودعات الأدوات، ومحرّر ترتيب الصفحة الرئيسية. تحديث **0.11.0** رفع صنّاع العمل فوق المصادر، ويضيف صف «من نفس السلسلة»، والبحث عن الممثلين والمخرجين بالاسم، وزر الإعلان. تحديث **0.10.0** أضاف صفحة صنّاع العمل: الممثلون والمخرجون وشركات الإنتاج ومواقع التصوير، وكل واحد منهم يفتح معلوماته وأعماله الأخرى. ويخفي المؤشر عن طريق ويندوز نفسه. تحديث **0.9.0** يعيد بناء المشغّل بطبقة تحكم فوق الصورة مثل Harbor وNuvio، ويحل اختفاء المؤشر من جذوره. التحديث **0.8.0** أضاف التحديثات الموقعة من داخل التطبيق ومثبت ويندوز، ويبني على جميع ميزات الإصدارات السابقة. تحديث **0.7.0** أضاف استوديو المظهر ليصمم كل مستخدم رِواق على ذوقه، ويخفي مؤشر الفأرة أثناء المشاهدة. التحديث **0.6.0** أعاد بناء الترجمة والصوت في المشغّل. التحديث **0.5.1** أصلح أول ملاحظتين من الاستخدام الفعلي على ويندوز: بطء عرض الكتالوجات مع الإضافات الكثيرة، والمشغّل الذي لا يملأ الشاشة. الإصدار **0.5.0 التجريبي** أضاف نسخاً احتياطياً مشفّراً ينقل رِواق إلى جهاز جديد، والحلقات التالية وتقويم المسلسلات، وتسجيل Trakt اللحظي، وفحصاً للتحديثات. تفاصيل التغييرات في [ملاحظات 0.5](docs/RELEASE-0.5.md)؛ ملاحظات 0.4 في [RELEASE-0.4](docs/RELEASE-0.4.md).

## الجديد في 0.12.2

- **ولا مجلد فارغ بلا سبب:** كل مصدر في المجلد يظهر، حتى الفارغ منه، ومعه السبب:
  - الإضافة غير مثبتة؛
  - المصدر لم يستجب، مع زر «أعد المحاولة»؛
  - المصدر لم يرجع شيئاً؛
  - الكتالوج يحتاج بحثاً؛
  - يحتاج مفتاح TMDB أو Client ID لـ Trakt؛
  - عناوين TMDB بلا معرّف IMDb؛
  - مصدر من نوفيو لا يقرؤه رِواق بعد.
- **مصادر TMDB الكثيرة لا تخسر عناوينها:** أربعة طلبات فقط في وقت واحد، ومحاولة ثانية عند الفشل، حتى لا يتجاوز المجلد حدّ طلبات TMDB.
- **عناوين TMDB بلا معرّف IMDb** تظهر إذا كانت عندك إضافة تفتح معرّفات TMDB مثل TMDB Addon أو AIOMetadata. وإذا لم تكن، يُذكر عددها بدل أن تختفي بصمت.
- ملصقات مصادر TMDB تأتي من TMDB نفسها.
- مصادر نوفيو غير المعروفة تبقى باسمها بدل أن تُحذف.

## الجديد في 0.12.1

- **مجلدات نوفيو لم تعد فارغة:** أغلب مجلدات نوفيو مبنية على مصادر TMDB، مثل سلاسل الأفلام والاستوديوهات والشبكات والاكتشاف والممثلين والمخرجين، أو على قوائم Trakt العامة. رِواق صار ينقلها ويقرأها بدل أن يتجاهلها.
- عناوين TMDB تُطابَق مع معرّفات IMDb لتفتح في إضافاتك، والمطابقة تُحفظ لتسريع المرات التالية.
- **مفتاح TMDB من نوفيو:** يُنقل مع الربط إذا اخترته، ويُحفظ مشفّراً. إذا كان عندك مفتاح في رِواق يبقى كما هو.
- **رسالة واضحة داخل المجلد** إذا احتاج مفتاح TMDB أو Client ID لـ Trakt، مع زر يفتح الإعدادات المناسبة.
- **مصادر جديدة في محرّر المجلد:**
  - استوديوهات وشبكات جاهزة: Marvel Studios وPixar وNetflix وHBO وغيرها.
  - رابط تلصقه من TMDB أو Trakt.
- **إذا نقلت مجموعاتك من نوفيو بالإصدار 0.12.0، أعد «الربط مع نوفيو» مرة.** المجموعات نفسها تتحدّث ولا تتكرر.

## الجديد في 0.12

- **المجموعات** (قسم جديد في القائمة):
  - المجموعة تضم مجلدات، والمجلد يجمع كتالوجات من إضافاتك مع عناوين تختارها بنفسك وترتّبها كما تحب.
  - لكل مجموعة ومجلد رمز تعبيري أو صورة غلاف، وللمجلد شكل بطاقة: ملصق أو عريض أو مربّع.
  - عرض بالتبويبات أو بالصفوف، وقوالب جاهزة للبداية.
  - **ثبّت المجموعة على الرئيسية** فتظهر مجلداتها كبطاقات.
  - **أضف لمجموعة** من صفحة أي عمل.
  - **تصدير بصيغة نوفيو** (نسخ أو ملف)، واستيراد المجموعات من أي تطبيق نوفيو بلصق النص.
- **الربط مع نوفيو:**
  - رِواق يقرأ بيانات **Nuvio Desktop / Nuvio HTPC** على نفس الجهاز، وهي ما يزامنه حسابك في نوفيو، أو ملف **النسخة الاحتياطية** من نوفيو.
  - اختر الملف الشخصي وما تريد نقله: **الإضافات** (بحالة التفعيل)، **المجموعات**، **المكتبة**، و**مستودعات الأدوات (Plugins)**.
  - لا يطلب كلمة مرور نوفيو ولا يتصل بخوادمه.
- **ترتيب الصفحة الرئيسية** في الإعدادات:
  - رتّب الأقسام أو أخفِها: الواجهة، نكمل الحكاية، الحلقات التالية، المجموعات المثبّتة، الكتالوجات.
  - رتّب صفوف كل كتالوج أو أخفِها.

## الجديد في 0.11

- **صنّاع العمل فوق المصادر** في صفحة التفاصيل، مباشرة بعد طاقم التمثيل.
- **من نفس السلسلة:** أجزاء الثلاثية أو السلسلة بالترتيب، مثل ثلاثية فارس الظلام، مع رقم كل جزء وعلامة على العمل اللي تتصفحه.
- **ابحث عن الأشخاص:**
  - اكتب اسم ممثل أو مخرج في البحث، بالعربي أو بالإنجليزي، فيظهر صف «أشخاص» فوق النتائج.
  - اضغط على أي شخص تطلع معلوماته وأعماله.
- **زر الإعلان** يفتح الإعلان الرسمي على يوتيوب، عندما توفّره الإضافة.

## الجديد في 0.10

- **طاقم التمثيل** تحت وصف العمل: صورة كل ممثل واسم الشخصية.
- **صنّاع العمل:**
  - الإخراج والكتابة والإنتاج والموسيقى والتصوير والمونتاج.
  - شركات الإنتاج والتوزيع.
  - **مواقع التصوير**، والمكان الذي تدور فيه الأحداث، وبلد الإنتاج.
  - الجوائز المسجّلة.
- **اضغط على أي اسم:**
  - الشخص: تاريخ ومكان الميلاد، المهن، الجنسية، عدد الجوائز، ونبذة عنه إن أضفت مفتاح TMDB.
  - الشركة: سنة التأسيس والمقر.
  - المكان: خريطة بموقعه.
  - ومع كل واحد منهم **أعماله الأخرى** بملصقاتها، وأي عمل منها يفتح تفاصيله مباشرة.
- المصدر **Wikidata** مجاناً وبدون مفتاح، وهو المصدر المفتوح الوحيد الذي يسجّل مواقع التصوير. مع مفتاح **TMDB** تظهر صور الممثلين والنبذ، ويبقى فريق العمل متاحاً إن تعطّل Wikidata.
- **المؤشر يختفي عن طريق ويندوز نفسه** (`ShowCursor`) بعد ثانيتين ونصف من التوقف فوق الصورة، مثل المشغلات الأصلية. يرجع مع أي حركة، أو إذا خرج من الصورة، أو إذا أوقفت المشاهدة.

## الجديد في 0.9

- **أدوات التحكم فوق الصورة:** نافذة شفافة تغطي الفيديو بالضبط وتتبع مكانه، ترسم فوق الصورة:
  - العنوان والحلقة في الأعلى.
  - شريط التقدم في الأسفل، مع علامات المقدمة والخاتمة، ووقت أي نقطة عند المرور عليها، ووقت الانتهاء.
  - أزرار التشغيل والصوت.
  - زر التخطي وبطاقة «الحلقة التالية».
  - لوحة الترجمة والصوت عائمة فوق الصورة.

  كل هذا يختفي مع المؤشر بعد ثانيتين ونصف من التوقف.

- **المؤشر يختفي فعلاً:** المؤشر فوق الصورة صار تتحكم فيه طبقة رِواق نفسها، بدل الاعتماد على MPV داخل النافذة المدمجة، وهو ما كان يفشل.
- **الماوس مثل المشغلات الكبيرة:** نقرة للإيقاف والتشغيل، ونقر مزدوج لملء الشاشة، والزر الأيمن للوحة الترجمة والصوت، والعجلة للصوت.
- **تبويب المصادر:** بدّل المصدر وأنت داخل المشغّل، وتكمل من نفس اللحظة.
- **تبويب الحلقات:** كل حلقات المسلسل حسب الموسم، مع علامة على اللي شاهدتها، واقفز لأي حلقة.
- **الانتقال التلقائي لمصدر آخر:** إن فشل المصدر يجرّب رِواق المصدر التالي من نفس الموضع، حتى ثلاث محاولات.
- **بطاقة الحلقة التالية** في آخر 45 ثانية، مع «شغّل الآن» أو «لاحقاً».
- **أزرار الوسائط في الكيبورد** (تشغيل/إيقاف، التالي، السابق، إيقاف) تعمل أثناء المشاهدة.

إن لم تظهر أدوات التحكم فوق الصورة على جهازك، أطفئ **أدوات التحكم فوق الصورة** من **الإعدادات ← المشغل والمصادر** فيعود المشغّل السابق.

## الجديد في 0.8

**التحديث من داخل التطبيق:** ثبّت نسخة Setup مرة واحدة، ثم يتولى رِواق تنزيل التحديثات الموقعة وتثبيتها عند الإغلاق، أو عبر زر «تثبيت وإعادة التشغيل» في الوقت الذي يناسبك. تبقى مكتبتك وإعداداتك وتقدمك محفوظة.

- قسم **الإعدادات ← التحديثات** لعرض الإصدار الجديد وملاحظاته ونسبة التنزيل، مع الإلغاء وإعادة المحاولة.
- تحقق تلقائي عند التشغيل ثم كل أربع ساعات، وتنزيل في الخلفية دون قطع المشاهدة.
- قناتان: مستقرة، ومستقرة مع تجريبية. التجريبية هي الافتراضية أثناء تطوير رِواق.
- تحكم مستقل بالتنزيل في الخلفية والتثبيت عند إغلاق التطبيق. يُؤجل التثبيت عند إيقاف تشغيل ويندوز.
- توقيع Ed25519 وحجم وبصمة SHA-512 للحزمة؛ يُرفض الملف التالف أو الإصدار الأقدم وتُفحص الحزمة مرة أخرى قبل تنفيذها.

التحديثات الداخلية تتطلب **النسخة المثبّتة**؛ النسخ المحمولة ونسخ التطوير تعرض الإصدارات فقط. [تفاصيل 0.8](docs/RELEASE-0.8.md) · [إعداد النشر والتوقيع للمطورين](docs/UPDATES.md).

## من 0.7

- **استوديو المظهر** في **الإعدادات ← المظهر والتخصيص**:
  - عشرة ثيمات جاهزة، منها «الأخضر الملكي» و«OLED» و«منتصف الليل» و«رمال».
  - ثمانية ألوان تعدّلها بنفسك مع تدرّج للون التمييز (أفقي أو عمودي أو مائل)، وتنبيه إن صار النص صعب القراءة.
  - خط التطبيق من خطوط ويندوز العربية أو أي خط مثبّت، وحجم الواجهة من 80% إلى 125%.
  - انحناء الزوايا، وكثافة العرض.
  - البطاقات: أسلوبها (زجاجي أو بسيط أو بإطار)، وحجمها، وانحناؤها، وتأثير المرور (ارتفاع أو توهّج أو لمعة)، وإظهار العناوين والتقييمات.
  - العرض الرئيسي (كامل أو مختصر أو مخفي)، وخلفية صفحة التفاصيل (صورة أو ضبابية أو لون ثابت)، وإخفاء عناصر من القائمة.
  - كل تغيير يظهر فوراً، ومعه زر تراجع وزر للعودة للافتراضي.
- **شارك تصميمك:** رمز نصي قصير تنسخه لأصدقائك، أو تلصق رمزاً وصلك. الرمز يحمل المظهر فقط، ولا شيء من حساباتك.
- **اختفاء مؤشر الفأرة** بعد ثانيتين من التوقف فوق الصورة، ويعود مع أول حركة.

## الجديد في 0.6

- **لوحة جانبية للترجمة والصوت:** تُفتح بزر الترجمة أو بالزر الأيمن على الصورة أو بحرف C، حتى في ملء الشاشة. الفيديو يصغر ليفسح لها ويبقى ظاهراً وشغّالاً، بدل القائمة القديمة التي كانت تغطيه.
- **ترجمات مرتبة وواضحة:** كل ترجمة باسم إصدارها واسم الإضافة وصيغتها، مجمّعة حسب اللغة (بأسماء عربية وبعدد كل لغة) ولغتك المفضلة أولاً، مع فرز «الكل / مدمجة / الإضافات» وعلامة للترجمات الإجبارية وترجمات الصم وضعاف السمع. الضغط يجرّب الترجمة فوراً دون إغلاق اللوحة.
- **ترجمة عربية تلقائية:** إن لم يحمل الملف ترجمة بلغتك الأولى، يجلب رِواق أفضل ترجمة بها من إضافاتك ويخبرك من أين جاءت. يمكن إيقافه.
- **مزامنة سريعة:** اعرض جمل الترجمة حول اللحظة الحالية واضغط الجملة التي سمعتها للتو، فيُضبط التوقيت عليها. إضافة إلى أزرار ±0.1 و±0.5 ثانية.
- **مظهر الترجمة:** الحجم والارتفاع ولون النص والحدود وسماكتها والظل والخلفية وشفافيتها والخط العريض، ومعاينة فورية، ويطبق على المشاهدة مباشرة ويُحفظ.
- **ترجمة ثانية:** اعرض ترجمتين معاً، مثلاً العربية والإنجليزية.
- **الصوت:** المسارات بلغتها وترميزها وقنواتها (5.1، 7.1)، وتأخير الصوت، وتضخيم حتى 150%.
- **«ينتهي عند»** بجانب مدة العمل.

## الجديد في 0.5.1

- **الكتالوجات تظهر أول بأول:** كان رِواق ينتظر آخر إضافة قبل أن يعرض أي شيء، ويطلب الكتالوجات في دفعات ثابتة تنتظر كل واحدة منها أبطأ إضافة فيها. مع عشرات الإضافات، إضافة معطلة واحدة كانت تؤخر الرئيسية كلها. الآن يظهر كل صف فور وصوله بترتيب إضافاتك، والطلبات تجري في مجموعة متواصلة، ومهلة الكتالوج 10 ثوانٍ بدل 16. الإضافة التي تفشل لا تُطلب ثانية لدقيقتين، والكتالوج الناجح يبقى محفوظاً عشر دقائق فيعود التنقل فورياً.
- **ملء الشاشة فعلاً:** تبدأ المشاهدة بملء الشاشة، والصورة تغطي الشاشة من الحافة للحافة بدل الإطار الذي يحيط به الشريط العلوي وأدوات التحكم. أدوات التحكم تظهر فوق الصورة عند تحريك الفأرة، وEsc أو النقر المزدوج أو F للخروج. يمكن إيقاف ذلك من **الإعدادات ← المشغل والمصادر ← ملء الشاشة عند التشغيل**.
- **تعبئة الشاشة (اختياري):** للأفلام العريضة ذات الأشرطة السوداء، من **إعدادات المشغل ← ملاءمة الصورة** أو من الإعدادات. تقص حواف الصورة، ومغلقة افتراضياً.
- **إعادة ضبط سطح الفيديو** بعد دخول ملء الشاشة وخروجه وبعد تغيير حجم النافذة، لأن مساحة النافذة تتغير بعد أن تقيسها الواجهة.

## الجديد في 0.5

- **نسخ احتياطي مشفّر:** بيانات رِواق مقفلة بحساب ويندوز الحالي، فإعادة تثبيت ويندوز أو جهاز جديد كانت تعني خسارة كل شيء. الآن تحفظ ملفاً واحداً `.riwaq` مشفّراً بعبارة مرور لا يعرفها غيرك، وتستعيده في أي مكان: الملفات الشخصية ومكتباتها وطوابيرها وسجلها وإعداداتها واختصاراتها والإضافات. المفاتيح والحسابات لا تُضمَّن إلا إن طلبت ذلك صراحة، ورموز الحماية الأبوية تنتقل دائماً.
- **الحلقات التالية:** في الرئيسية، الحلقة التالية من كل مسلسل تتابعه، بعد آخر حلقة أنهيتها، مع شارة «جديدة» لما عُرض في آخر أسبوعين وعدد الحلقات المنتظرة.
- **تقويم المسلسلات:** تبويب في مكتبتي يعرض حلقات مسلسلاتك للأسبوع الماضي والشهر القادم، مجمّعة حسب اليوم بتوقيتك.
- **شاهدت حتى هنا:** في صفحة المسلسل علّم الحلقة كمشاهدة أو ألغِ العلامة، أو علّم كل ما قبلها دفعة واحدة إن كنت تابعت المسلسل في مكان آخر.
- **Trakt لحظياً (Scrobble):** اختياري؛ يُظهر ما تشاهده الآن في Trakt ويسجّله عند الإيقاف بعد 80%. لا يُحسب العمل مرتين أبداً، ولا تضيع مشاهدة إن انقطع الاتصال.
- **فحص التحديثات في 0.5:** بدأ بتنبيه يفتح صفحة الإصدار؛ تطور في 0.8 إلى تنزيل وتثبيت الحزم الموقعة داخل النسخة المثبّتة.
- **عربية أدق:** البحث في المكتبة والقنوات يتفقان الآن على ة/ه وأشكال الحروف الفارسية والأرقام الهندية، والأعداد تتبع قواعد العدد العربي (حلقتان، 3 حلقات، 11 حلقة).

## من 0.4

- **طابور مشاهدة شخصي:** أضف فيلمًا أو حلقة من التفاصيل، ثم قدّمها أو أخّرها أو أزلها من مكتبتي. يتسع الطابور لـ200 عنصر ويمنع تكرار الحلقة نفسها، ويُحفظ لكل ملف شخصي على حدة.
- **مكتبة بخمسة أقسام:** قائمتي، متابعة المشاهدة، طابور المشاهدة، سجل المشاهدة، وقوائم المنصات. البحث يتجاهل التشكيل واختلاف الألف والياء، مع فلترة حسب نوع المحتوى وفرز بالاسم أو السنة خارج الطابور.
- **متابعة أدق للحلقات:** تعتمد المتابعة على آخر مشاهدة لكل عنوان؛ إكمال حلقة أحدث لا يعيد حلقة قديمة غير مكتملة إلى الواجهة. تظهر علامات الإكمال وتُستبعد الحلقات ذات تاريخ العرض المستقبلي المعروف من التشغيل.
- **إدارة السجل محليًا:** ضع علامة «شاهدته» أو احذف موضع المشاهدة من ملفك الشخصي. هذه الإجراءات لا تُرسل سجلًا إلى Trakt أو المنصات المرتبطة؛ أوقف تشغيل العنوان قبل تعديل سجله.
- **تبديل المشاهد أثناء التشغيل:** يتوقف الفيديو ويُحفظ موضعه للمشاهد الحالي قبل الانتقال، فتظل مكتبة كل مشاهد وتقدّمه وطابوره منفصلة.
- **متابعة تلقائية اختيارية:** عند انتهاء الفيديو يبدأ العنوان الأول في الطابور، ثم الحلقة التالية المتاحة إذا كان الطابور فارغًا. الخيار مغلق افتراضيًا، وأزرار الحلقة السابقة والتالية تبقى خاصة بحلقات المسلسل.

يُزال العنصر من الطابور بعد أن يؤكد المشغل تحميله. إذا تعذّر جلب التفاصيل أو العثور على مصدر مناسب، يبقى في الطابور. الطابور محلي لهذا الجهاز والملف الشخصي ولا يُزامَن إلى Stremio أو المنصات.

## التنزيل

نزّل أحدث نسخة من [صفحة الإصدارات](https://github.com/ABADIOSA/riwaq/releases). اختر ملف **Riwaq-Setup-0.12.2-win-x64.exe** للتثبيت وتفعيل التحديثات الداخلية، أو النسخة المحمولة للاستخدام اليدوي. كلاهما يتضمن Node.js وMPV. يُبنى كل إصدار على ويندوز عبر GitHub Actions، ويُرفق معه ملف `SHA256SUMS.txt` ببصمة الملف.

تحقّق من الملف قبل تشغيله بمقارنة بصمته:

```powershell
Get-FileHash .\Riwaq-Setup-0.12.2-win-x64.exe -Algorithm SHA256
```

> [!WARNING]
> الملف **غير موقَّع** بشهادة نشر ويندوز، وقد يظهر تنبيه SmartScreen. تعليمات بناء نسخة من المصدر في [التطوير والبناء](#التطوير-والبناء).

## البدء

1. افتح **حساب ستريميو** وسجّل الدخول عبر صفحة ستريميو الرسمية في المتصفح.
2. يعود رِواق ليستورد إضافاتك المهيأة والمكتبة ومواضع المشاهدة. يمكن إضافة روابط manifest.json يدويًا أيضًا.
3. اختر عنوانًا، ثم الحلقة والمصدر. الفيديو يعمل داخل رِواق؛ زر التصغير يبقيه في مشغل مصغّر أثناء التصفح.
4. من **الإعدادات ← مكتبة البيانات** أضف مفاتيح خدماتك، ثم اختبر الاتصال.
5. من **الحسابات والربط** اربط المنصات؛ تظهر قوائم Trakt وSimkl في مكتبتي، وLetterboxd عبر كتالوجات الإضافة.
6. من **بث مباشر** أضف قائمة M3U أو اشتراك Xtream تملكه؛ يُقرأ دليل البرامج تلقائياً إن وفّره المزوّد.

لا تضع كلمات المرور أو مفاتيح API في المحادثات أو ملفات المصدر. بيانات رِواق الشخصية محفوظة مشفرة تحت `%APPDATA%/Riwaq/profile.bin`.

### استخدام طابور المشاهدة

1. افتح تفاصيل الفيلم أو المسلسل، واختر الحلقة إن وجدت، ثم اضغط **أضف إلى الطابور**.
2. افتح **مكتبتي** ثم **طابور المشاهدة** لترتيب العناصر بالسهمين أو إزالتها. افتح العنصر لاختيار مصدره وتشغيله.
3. للانتقال تلقائيًا عند انتهاء الفيديو، افتح **الإعدادات** ثم **المشغل والمصادر** وفعّل **متابعة المشاهدة تلقائياً**. يستخدم التطبيق أول مصدر متوافق وفق إعداداتك، ويعطي الطابور الأولوية على الحلقة التالية.

### النسخ الاحتياطي والانتقال لجهاز جديد

1. افتح **الإعدادات ← النسخ الاحتياطي**، واكتب عبارة مرور من 8 أحرف على الأقل مرتين، ثم **حفظ نسخة احتياطية**.
2. احتفظ بالملف `.riwaq` وبعبارة المرور. **لا نستطيع فتح النسخة إن نسيت العبارة.**
3. على الجهاز الجديد افتح القسم نفسه، واختر الملف، واكتب العبارة، وراجع المعاينة ثم **استعادة الآن**.

النسخة العادية لا تحمل الأسرار: روابط الإضافات المهيأة (فيها مفاتيحها غالباً)، وتسجيل دخول ستريميو، ومفاتيح الخدمات، وحسابات المنصات، واشتراكات القنوات، ووجهات الإشعارات. يخبرك رِواق بما تُرك منها لتعيد إضافته. ضع علامة **تضمين مفاتيحي وحساباتي** لنقل كل شيء — حينها أمان النسخة بقدر عبارة المرور وحدها.

الاستعادة تستبدل الملفات الشخصية ومكتباتها وإعداداتها. المفاتيح التي لا تحملها النسخة تبقى كما هي على هذا الجهاز، ويُحفظ ملفك الحالي بجانبها باسم `profile.before-restore.bin` للتراجع على هذا الجهاز. إن قفلت قسم **الإعدادات** برمز الحماية، فالنسخ والاستعادة يتطلبان الرمز أيضاً.

### الحلقات التالية والتقويم

- تظهر **الحلقات التالية** في الرئيسية للمسلسلات المحفوظة في مكتبتك أو في طابورك أو التي شاهدت منها حلقة. المسلسل الذي تشاهد حلقته الآن يبقى في «نكمل الحكاية؟».
- **مكتبتي ← التقويم** يعرض حلقات هذه المسلسلات للأسبوع الماضي والشهر القادم.
- إن تابعت مسلسلاً في تطبيق آخر، افتح الحلقة التي وصلت إليها واضغط **شاهدت كل ما قبلها** لتبدأ الحلقات التالية من هناك.

### Trakt لحظياً

بعد ربط Trakt وتفعيل **تسجيل المشاهدة في Trakt** من **الحسابات والربط**، فعّل **تسجيل لحظي (Scrobble)**. عند الإيقاف قبل 80% يحفظ Trakt موضعك فقط؛ بعد 80% تُسجَّل المشاهدة. إن انقطع الاتصال لحظة الإيقاف تُحفظ المشاهدة في طابور الإرسال وتُرسل لاحقاً.

## الميزات المتوفرة

ميزات 0.3 محفوظة في هذا الإصدار، بما فيها محرّك المصادر والبث المباشر والملفات الشخصية وأدوات المشغل.

### محرّك المصادر — يشرح لماذا رتّب كما رتّب

مسار من أربع مراحل: قراءة، ثم استبعاد، ثم تقييم، ثم تصنيف إلى طبقات.

- **قراءة**: الدقة، ونوع HDR (DV، HDR10+، HDR10، HLG)، ومرمّز الفيديو وعمق البت، ونوع النسخة (REMUX، BluRay، WEB-DL…)، والصوت وعدد قنواته، والحجم وعدد المصادر، وفريق الإصدار، والنسخة الخاصة، والموسم والحلقة، وحالة التخزين على debrid، واللغات من الكلمات ومن أعلام الدول.
- **استبعاد**: العيّنات والمقاطع الدعائية والمواد الإضافية، والأوصاف التي تحمل روابط ودعاية، والنسخ المضخّمة صناعياً، وتصوير الصالة، والحلقة أو الموسم الخطأ، والملفات الأصغر من أن تطابق وصفها، والتورنت بلا مصادر. ولك ثلاثة مستويات: صارم ومتوازن ومطفأ، مع حدّ اختياري لحجم الملف.
- **تقييم وتصنيف**: كل نقطة مسجّلة باسمها. اضغط زر المعلومات بجانب أي مصدر لترى تفصيل نقاطه، واضغط «عرض المستبعَد» لترى ما حُذف ولماذا.
- **الأولوية العربية ليست مكافأة إضافية**: يميّز المحرّك بين «مترجم» و«مدبلج»، فالترجمة العربية تُقدَّم حين تطلبها في لغات الترجمة، والدبلجة تُقدَّم فقط حين تطلبها في لغات الصوت — ولا تُفرض على من يريد الصوت الأصلي.

### بث مباشر بدليل برامج

قوائم M3U واشتراكات Xtream Codes، مع قراءة XMLTV واختيار العنوان العربي حين يوفّره المزوّد. شبكة قنوات بالشعارات وبرنامج الآن والتالي وشريط تقدّم، وتصنيفات ومفضلة وبحث يتجاهل التشكيل واختلاف الألف والياء والتاء المربوطة، ودليل برامج بخط زمني ومؤشر «الآن»، وإعادة مشاهدة للبرامج المنتهية بأساليب default وappend وshift وflussonic وXtream.

### مشغّل أوسع

تخطي المقدمة والخاتمة من فصول الملف مع زر أو تخطٍ تلقائي، وعلامات المقاطع على شريط التقديم، وتكرار مقطع A/B، ومؤقّت نوم، والتقاط صور، وتأخير الصوت، وتكبير وإزاحة الصورة، وترجمة ثانوية، ولوحة إحصائيات، ومرشّحات صورة مبنية على محرّك MPV، وتحويل HDR إلى SDR، ومخزون وإعادة اتصال للبث المباشر، و**كل مفاتيح المشغّل قابلة لإعادة التعيين** مع كشف التعارض.

### ملفات شخصية وحماية أبوية

حتى ستة ملفات شخصية، لكل واحد مكتبته وتقدّمه وقوائمه وإعداداته. رمز حماية من 4 إلى 8 أرقام مخزّن بتجزئة scrypt بملح مستقل، وأقسام يمكن قفلها، وفتح يعيش في الذاكرة فقط فيُقفل كل شيء عند التبديل أو الإغلاق.

### حضور وإشعارات — اختيارية بالكامل

حضور Discord عبر أنبوب محلي بمعرّف تطبيق تملكه أنت، بثلاثة مستويات تفصيل. وإشعارات عبر Webhook من Discord أو بوت Telegram تملكه، مع رفض التحويلات والتحقق من المضيف الرسمي.

### الواجهة والتصفح

- سبعة ثيمات، ثلاثة تخطيطات (سينمائي، جانبي، علوي)، بطاقات زجاجية/بسيطة بأحجام مختلفة، تقليل الحركة وإخفاء المكتمل والتقييمات، وإعدادات قابلة للبحث.
- كتالوجات وبحث وتفاصيل ومواسم وحلقات ومفضلة وتقدم محلي، مع إدارة ترتيب الإضافات وتفعيلها واستيراد/تصدير روابطها.
- MPV مدمج داخل نافذة رِواق: ملء شاشة، تصغير داخل التطبيق، مسارات صوت وترجمة، ملفات SRT/ASS، أولوية لغات، حجم وتأخير الترجمة، سرعة ونسبة صورة وضبط سطوع/تباين/تشبع/جاما، تسريع عتاد وخيار HDR، واستئناف وتشغيل الحلقة التالية.

## حدود واضحة

- استيراد Stremio في اتجاه واحد إلى رِواق. التغييرات المحلية لا تُرفع لحساب ستريميو. الإضافات المحذوفة من السحابة لا تُحذف محليًا تلقائيًا.
- مصادر التورنت/infoHash تحتاج **Stremio Service** تعمل على الجهاز؛ العنوان الافتراضي `http://127.0.0.1:11470`. الخدمة غير مرفقة. مصادر HTTP/HTTPS المباشرة لا تحتاجها.
- المشغل المصغّر يبقى داخل رِواق؛ ليس نافذة PiP مستقلة فوق التطبيقات الأخرى. HDR يعتمد على المصدر والشاشة وإعدادات ويندوز، ولم يُتحقق منه على شاشة HDR فعلية أو عدة شاشات بدقات مختلفة.
- الربط مع Letterboxd عبر Stremboxd طرف ثالث معلن، وليس OAuth رسميًا. واجهة Letterboxd الرسمية تتطلب موافقة خاصة. لا نطلب كلمة مرور Letterboxd. CSV لقطة محلية لا تحدث الحساب؛ يستورد أول 500 صف مع مطابقة دقيقة للاسم والسنة، ويبلغ عن غير المتطابق والزائد.
- Trakt يحتاج Client ID وClient Secret من تطبيق المستخدم، وSimkl يحتاج Client ID. استيراد Trakt محدود حاليًا بـ1,000 عنوان لكل نوع في المزامنة. تسجيل الإكمال مغلق افتراضيًا؛ عند تفعيله ترسل الأعمال عند 90%، ويعاد إرسال المتعثر مع مزامنة القوائم التالية. Simkl حاليًا قراءة قوائم فقط.
- **رِواق لا يوفّر قنوات ولا اشتراكات ولا محتوى.** مصادر البث المباشر تأتي من قوائم يملكها المستخدم، وبيانات الاشتراك تُحفظ مشفّرة ولا تصل إلى الواجهة أبداً؛ القنوات تُعنون بمفتاح مبهم ويُترجم داخل العملية الرئيسية عند التشغيل فقط.
- تخطي المقدمة يعتمد على فصول الملف. عند غيابها يُستخدم استدلال متحفّظ ضمن نافذة المقدمة فقط، ولا يوجد تكامل مع AniSkip أو قواعد فصول خارجية.
- مرشّحات الصورة مبنية على خيارات MPV نفسها (scale وdeband وsigmoid). **لا نرفق ملفات Anime4K ولا أي شيدر من طرف ثالث**؛ من يملك سلسلة GLSL يشير إليها من الإعدادات.
- حضور Discord يحتاج معرّف تطبيق من المستخدم وتطبيق Discord يعمل على الجهاز؛ لم يُختبر مع عميل Discord حقيقي.
- الملفات الشخصية تفصل المكتبة والتقدّم والقوائم والإعدادات. الإضافات ومفاتيح الخدمات وحسابات المنصات ومصادر القنوات مشتركة بين الجميع عن قصد.
- **عبارة مرور النسخة الاحتياطية لا تُستعاد.** رِواق لا يحتفظ بها ولا يستطيع فتح نسخة بدونها.
- التقويم والحلقات التالية يعتمدان على تواريخ العرض التي تقدمها إضافاتك (Cinemeta عادة)، لأحدث 40 مسلسلاً تتابعه. الحلقة بلا تاريخ مقروء لا تظهر في التقويم، والحلقات الخاصة (الموسم 0) لا تُعد «التالية».
- Trakt اللحظي لم يُختبر مع حساب Trakt حقيقي؛ اختُبر مقابل شكل الواجهة الموثّق. يعتبر Trakt المشاهدة مكتملة عند 80% في الوضع اللحظي، و90% في وضع الإكمال.
- فحص الإصدارات يرسل طلبًا مجهولًا إلى GitHub كل أربع ساعات ويمكن إيقافه. قد يتعذر بسبب انقطاع الاتصال أو حد الطلبات؛ تظهر إعادة المحاولة داخل التطبيق. التنزيل والتثبيت يتطلبان حزمة موقّعة والنسخة المثبّتة، ولا يتطلبان حساب GitHub من المستخدم.
- الربط مع نوفيو يقرأ بيانات نوفيو المحفوظة على نفس الجهاز أو ملف نسخته الاحتياطية، ولا يتصل بحساب نوفيو على خوادمه: الخادم الرسمي يتطلب مفتاح عميل لا ينشره نوفيو في شيفرته المصدرية. إذا كنت تستخدم نوفيو على الجوال فقط، صدّر المجموعات والصقها. مصادر TMDB تحتاج مفتاح TMDB، وقوائم Trakt تحتاج Client ID من تطبيقك في Trakt، ولا يلزم تسجيل الدخول. العنوان الذي لا يجد له TMDB معرّف IMDb لا يظهر، لأن إضافاتك لا تستطيع فتحه. **رِواق لا يشغّل أدوات نوفيو البرمجية (Plugins)**: ينقل قائمة المستودعات فقط، لأنها شيفرة JavaScript من أطراف أخرى. لم يُختبر الربط على نسخة نوفيو حقيقية بعد؛ بُني على صيغة ملفات نوفيو المفتوحة المصدر.
- البحث عن الأشخاص يشمل من لهم معرّف IMDb في Wikidata فقط، و«من نفس السلسلة» يعتمد على تسجيل Wikidata للأجزاء. الإعلان يفتح في المتصفح لأن رِواق لا يرفق أداة لتشغيل يوتيوب داخل المشغّل.
- صنّاع العمل من Wikidata، وهي موسوعة يحرّرها متطوعون: بعض الأعمال ناقصة أو بلا مواقع تصوير، والأسماء بالعربية إن توفّرت وإلا بالإنجليزية. «الأعمال الأخرى» تشمل ما له معرّف IMDb فقط، ونوع العمل (فيلم/مسلسل) يُقرأ من Wikidata وقد يخطئ فيجرّب رِواق النوع الآخر. خرائط المواقع صور من OpenStreetMap.
- لا يزال غير موجود: تنزيلات، بث للأجهزة (Chromecast/DLNA/AirPlay)، Watch Party، DVR، معاينة صور عند التقديم (trickplay)، متجر إضافات داخل التطبيق، وPiP على مستوى النظام.
- الإضافات الحديثة HTTP/HTTPS مدعومة. نقل legacy/IPFS وNZB والأرشيفات غير مدعوم؛ روابط YouTube والخارجية تفتح في المتصفح.
- اختبارات OAuth ومفاتيح الخدمات والبث المباشر والإشعارات محاكاة بعقود API ومدخلات حقيقية الشكل؛ لم تُستخدم حسابات ولا اشتراكات شخصية فعلية في التحقق. راجع [VERIFICATION.md](VERIFICATION.md) لما جرى اختباره فعلاً وما لم يجرِ.

## التطوير والبناء

المتطلبات: Windows x64 وNode.js 24 وnpm. لا تحتاج Rust أو Visual Studio؛ Koffi يستخدم ملفًا ثنائيًا جاهزًا لاستدعاءات Win32.

> [!IMPORTANT]
> **ابنِ على ويندوز.** البناء المتقاطع من Linux أو macOS يمرّ بلا خطأ لكنه ينتج ملفًا معطوبًا: يثبّت npm نسخة Koffi الخاصة بنظام البناء لا بويندوز، فيُقلع التطبيق ثم يفشل في إنشاء سطح الفيديو المدمج. سير عمل [`release.yml`](.github/workflows/release.yml) يبني على `windows-latest` لهذا السبب تحديدًا.

```powershell
npm ci
node scripts/fetch-mpv.mjs
npm test
npm run check
npm run build
npm start
npm run package
```

يتحقق سكربت MPV من SHA-256 للأرشيف المثبت الإصدار. المنتج في `release/`. أغلق أي نسخة قيد التشغيل قبل إعادة الحزم.

لإصدار نسخة جديدة: اضبط سر التوقيع `RIWAQ_UPDATE_PRIVATE_KEY` مرة واحدة، ثم ادفع وسمًا يطابق إصدار الحزمة مثل `v0.8.0`. يبني سير العمل المثبت والنسخة المحمولة ويوقّع بيانات التحديث وينشر الملفات بعد اكتمالها. يمكن اختيار القناة المستقرة عند تشغيل سير العمل يدويًا. اتبع [دليل التحديثات](docs/UPDATES.md).

اختبار فعلي من المصدر بملف شخصي جديد ومعزول:

```powershell
$env:RIWAQ_DATA_DIR = Join-Path (Get-Location) '.cache/smoke-profile-new'
$env:RIWAQ_SMOKE = '1'
npm start
```

اختبار النسخة المحمولة:

```powershell
node scripts/test-packaged.mjs release/Riwaq-0.12.2-win-x64.exe
```

لا تستخدم RIWAQ_SMOKE مع ملفك الشخصي الحقيقي؛ يضيف بيانات اختبار. اختبار المصدر يستخدم كتالوج Cinemeta الحقيقي ومصدر فيديو محليًا اصطناعيًا. CI يفحص المصدر والبناء دون GPU؛ الاختبار الأصلي يحتاج جلسة سطح مكتب ويندوز.
