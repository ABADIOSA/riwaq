### Root causes and file pointers

- `src/App.jsx`, `Details.jsx`, `src/title.css`: opening Details reset the shared document offset and hidden siblings collapsed browsing layout. Details now owns scrolling and reversibly restores background styles/inertness/focus. Explicit navigation and playback discard suspended catalog ownership and pending return frames.
- `src/session.css`, `src/identity.css`: unified-shell rules overrode independent identity geometry/ornaments. Rectangular overrides now target Classic.
- `UI.jsx`, `drag-scroll.js`, `HomeHero.jsx`, `TasteDiscovery.jsx`: initial-ref binding missed late/replaced rows; shared lifecycle-aware arrows/gestures preserve clicks and menu actions.
- `CatalogBrowser.jsx`, `core/client.mjs`, `core/discover.mjs`, `SmartHome.jsx`: All lacked a full browse route. Real constituent keys/filters are retained. Unique card count no longer controls provider offsets or proves page exhaustion. Explicit retry bypasses failed catalog cache entries while retaining successful entries.
- `electron/offline.mjs`, `main.mjs`, `preload.cjs`, `OfflineLibrary.jsx`: artwork/Reveal stay main-only, filesystem use is reserved per ID, and ownership is rechecked after IO. Profile cleanup drains non-abortable artwork commits before deletion.
- `PlayerMenu.jsx`, `core/offline-media.mjs`: main-issued profile/video/session and source capabilities govern actions. Options are captured once per menu opening, avoiding parent ticks stealing keyboard focus.
- `vite.config.mjs`, `vite.web.config.mjs`: forced React JSX-runtime optimization created a second i18n singleton in development. Excluding the local translating runtime from forced optimization restores shared AR/EN state; production builds were separately tested.
