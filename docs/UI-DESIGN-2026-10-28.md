## Design system

Riwaq's appearance already lives in one place: `core/appearance.mjs` `themeVariables` writes the viewer's palette, radii, density gap and font onto the app root, and `src/studio.css` sets the card width per card size. The new layer, `src/tokens.css`, **adds semantic names on top of those values; it does not introduce new colours.** Older stylesheets are untouched (their pixel output is unchanged); new and rebuilt surfaces use the tokens.

| Token | Value (from) | Use |
| --- | --- | --- |
| `--surface`, `--surface-raised`, `--text-strong`, `--text-muted`, `--border` | `--bg`, `--panel`/`--raised`, `--text`, `--muted`, `--line` (viewer palette) | Page background, cards and bars, primary and secondary text, hairlines |
| `--accent`, `--accent-soft`, `--accent-ink` | viewer palette | Selected tab, focus ring, primary button text |
| `--space-1`…`--space-7` | 4, 8, 12, 16, 24, 32, 48 px | The 4 px base the shell already writes (gaps 8/12/16/24, page padding 24–32) |
| `--page-gutter` | `--session-gutter` (clamp 24 px – 3.8 vw – 76 px) | Inline padding of every page in the shell |
| `--card-width` | 135 / 162 / 190 px (compact / comfortable / large) | Poster grid track minimum; grids use `auto-fill`, so columns follow the content width |
| `--grid-gap` | `--gap` (10 / 16 / 24 by density) | Grid gaps |
| `--radius`, `--radius-lg`, `--poster-radius` | viewer's corner choice | Controls, panels, posters |
| `--control-height` | 40 px | Back, tabs' minimum, Load more (≥ WCAG 2.5.8's 24 px; primary actions aim for 44 px where the row allows) |
| `--focus-ring` | 2 px solid `--accent`, offset 3 px | Every focusable control on rebuilt surfaces |
| `--elev-1`, `--elev-2` | `0 6px 18px #0003`, `0 18px 48px #0006` | Raised bars, menus |
| `--motion-fast`, `--motion-base` | 120 ms, 220 ms; 0 under `.reduced-motion` or `prefers-reduced-motion` | Hover and state transitions only; nothing autoplays |

**Type:** the page title is the shell's `h1` (Naskh headings under the Riwaq identity, Segoe UI under Classic; `identity.css` decides), section titles `h2` 20 px, body 14 px, captions 12 px `--text-muted`, eyebrow 11 px `--accent`. Arabic and Latin share the font stack; titles from addons carry `dir="auto"`. **Icons:** lucide at 16/18/20 px; arrows follow reading direction (Back is `ArrowRight` in Arabic and mirrored in English by `ltr.css`). **Responsive:** the content column already excludes the sidebar (`--nav-width`); the grid needs no breakpoints of its own. At ≤ 760 px the sidebar becomes the drawer and the page gutter falls to 16 px. **Identity:** the Riwaq identity's arches and the Classic rectangles both apply to cards on the new page because it uses the shared `Poster` and `.poster-grid`.

## Page specifications

### See all (#112)

A page in the content area, between the masthead and the sidebar. Not a dialog: no backdrop, the sidebar and search stay usable.

```
browse page (section, fixed scroller in the content region; view underneath stays mounted, hidden and inert)
  page-body
    Back («رجوع», Details' back button)               ← Escape does the same
    page heading: eyebrow «عرض الكل» · h1 name · provider/type line
    coverage line: «N عنوان من M كتالوج حتى الآن» (+ «اكتمل» per exhausted catalog)
    catalog tabs (filter-tabs tablist): الكل · one per catalog   ← only with ≥ 2 catalogs
    filters (one select per declared filter of the selected catalog; required ones have no «الكل»)
    poster grid (shared Poster; columns from --card-width)
    status: Busy while loading · Empty when a catalog returned nothing · inline warning per failed catalog with «إعادة المحاولة»
    Load more (also loads automatically as the end of the grid nears, until an error)
```

Behaviour:
- **Opening** keeps the row's catalogs (`row.rows` for a group's All and Discover's blended rows), their opaque keys, the row's selected addon filters, the search query when opened from search, and each catalog's cursor (`page`, provider `skip`). Focus moves to the page heading.
- **Paging:** "All" asks the next page of every catalog that has one, at most four at once, and appends the new titles interleaved after the loaded ones, so cards never reorder under the pointer. A catalog tab pages that catalog. The provider's own page size advances `skip`, never the de-duplicated count; a page that adds nothing new still advances (no stall); an empty page ends that catalog. A failure is kept per catalog; retry asks only the failed catalogs with `retryFailed`, and the loaded titles stay.
- **Filters:** changing a filter restarts that catalog at its first page with the new value (a new request generation; late replies of the old one are ignored).
- **Details and Back:** a title opens Details over the page; the page stays mounted (scroll, tab, filters, loaded pages). Back from Details returns to the page with focus on the card. Back from the page returns to the row with focus on its See all button and the window where it was.
- **Ownership:** another destination, a profile switch, a lock, or a playback start closes the page and discards what Back would restore; a reply that arrives after that is dropped.
- **Density budget:** the grid spans the page body (≥ 90% of the content column's inner width) at every width. With the default card width (162 px) and gap (16 px) that is at least 8 columns at 1920, 6 at 1440, 5 at 1280, 3 at 980 and 740, and 2 at 390; cards stay between 135 and 260 px wide.

### Home (E1)

- **Resume first:** when Continue watching has titles, it is the first section after the hero and countdowns the viewer placed above it; Today's session follows it. Without history the session stays first.
- **Session, compact by default:** one band with the kicker, a short heading, the five durations, the mood chips and «كوّن جلستي». The decorative preview panel shows only in the full layout. «عرض أوسع» / «عرض مختصر» switches, saved per profile as `sessionExpanded` (default off; backups and accounts carry it through `safeSettings`). The plan result appears under the band as before. `showSession: false` still hides it entirely.
- **Taste compass starts folded on Home too:** heading, «اضبط ذوقك» and the recommendation row; the genre editor opens on request. Saved genres and feedback are unchanged.
- The showcase stays off unless the viewer turned it on; nothing autoplays.

### Player menu (#113)

Items unchanged: Take a screenshot, Copy magnet link (torrent sources), Download video. Under the magnet item, a one-line note tied with `aria-describedby`: «هذا المصدر تورنت بلا ملف ‎.torrent منفصل؛ رابط المغناطيس يحمل معرّفه ومتتبّعاته.» No second item copies the same value; no `.torrent` URL is invented; no stream URL is exposed.

### Rows (#111)

One drag implementation (`attachDragScroll`). Poster images opt out of native image dragging so a row gesture never turns into an image drag in Chromium. Short click opens, drag never opens, right-click and the Menu key keep the poster actions, vertical wheel and grids keep native page scrolling.

## Acceptance criteria

1. See all opens as a page (not `dialog`) for All and single catalogs from Home and Discover; at 1440 and 1280 the grid fills ≥ 90% of the content column with ≥ 6 and ≥ 5 columns; no horizontal page overflow at 1920–390 in Arabic and English.
2. Details from the page and Back restore tab, filters, loaded pages, scroll and focus; Back again restores the row's focus and the window offset.
3. Navigation, profile switch, lock and playback close the page; nothing late revives it.
4. A repeated provider page does not stall paging; a failed catalog is retried alone and loaded titles stay.
5. Home shows Continue watching before the session when it has titles; at 1440×900 without history the first catalog shelf starts within 1,300 px of the top (baseline 2,230).
6. Every horizontal row still drags with the mouse and keeps clicks; the new page's grid scrolls vertically with the wheel.
7. Every new Arabic string has English; `npm test`, `npm run check`, both builds and the Chromium suites pass; native MPV/HUD remains to be run on Windows.
