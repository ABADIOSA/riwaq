## لوحة الأدمن والخصوصية

القراءة محمية بسر مستقل METRICS_ADMIN_KEY؛ لا يُستخدم رمز GitHub لها. المشاركة معطلة افتراضياً، بمعرّف عشوائي وإصدار ومنصة فقط. الموافقة خارج المزامنة والنسخ الاحتياطية، ولا يتغير تشفير الحسابات. D1 يخزن بصمة مملحة وآخر نبضة؛ إيقاف المشاركة يحذف المنصة والإصدار ويمنع النبضة المتأخرة، والتنظيف اليومي يمسح القديم. الخدمة تفشل مغلقة دون السر ولا تعرض أصفاراً على فشل الاتصال. حدود الحجم/المعدل لا تجعل الأرقام دليلاً على عدد البشر ولا تمنع كل إساءة ممكنة.

[خطوات التفعيل ومعنى الأرقام والاحتفاظ](ADMIN.md#usage-dashboard). إعداد المفتاح ونشر Worker وإصدار تطبيق المشاهد قرارات لاحقة للمالك؛ لم يُنشأ سر أو نشر خارجي هنا. وثّقت معالجة عنوان الشبكة لدى الاستضافة، والحاجة لمراجعة سجلها ونسخها الاحتياطية وإشعار الخصوصية قبل تفعيل القياس للجمهور. التطبيق مجاني، بلا اشتراكات أو DRM أو قيود جديدة.

## التحقق والأدلة

- 882 اختبار Node، صفر فشل/تجاهل (871 في نقطة البدء +11). تشمل SQLite الفعلية: مصادقة اللوحة، إزالة التكرار، الفصل، انتهاء الاحتفاظ، حدود الطلب ومنع الحقول الزائدة. وتشمل سلامة بايتات الاستئناف ورد 200 وتغيّر ETag وإعادة فتح مكتبة التنزيلات بعد الوقف.
- Prettier وبناء سطح المكتب والويب ناجحة. تحذير حجم بعض حزم Vite مستمر ولا يُخفى.
- Chromium web smoke ناجح، بما فيه ملاءمة الصورة، حسابان/جهازان، النسخ المشفر وتأجيل إعدادات أثناء فيديو فعلي. نبضة اختيارية تصل عبر HTTP إلى SQLite، ولا تنتقل موافقتها عبر الحساب، وتزول من الأعداد عند الإلغاء.
- HUD Chromium: لوحة الترجمة، مفاتيح عربية/إنجليزية، قوائم السرعة، وإطار تحميل ثابت لا يعرض رد موضع سابق.
- Windows Electron/MPV: أدوات مدمجة ومنفصلة، صوت وترجمة ومسارات فعلية، الملاءمة/القص/التمديد، توقف/تقديم/F8 وتجميد الواجهة. اختبار نافذة HDR يستخدم فيديو SDR ولا يصادق على شاشة HDR أو Dolby Vision أو GPU المبلّغ.
- Windows offline review: تنزيل مباشر دون فتح المشغل، عدم بدء تشغيل متأخر بعد Stop، مدخلات النافذة الأصلية، حفظ الملفات والموسيقى عند رفض حذف ملف شخصي، وعرض أسماء الحلقات العربية/الإنجليزية، والتشغيل بعد تعطيل المصدر. لا استمرار نقل بعد إغلاق العملية ولا استئناف مضمون لرابط منتهي.
- أدمن Electron: الواجهة 980×780، عدادات fixture، محو حقل المفتاح وغيابه عن state، والفصل؛ نشر الإشعار بمحاكاة فقط، وبقاء البناء والتجربة المعزولة وصندوق الإشعارات كما هما.
- أدمن portable الحقيقي يعمل وقرأ 63 إصداراً: 219 تنزيل EXE وقت الفحص (140 مثبّت، 79 محمول)؛ خانة الاستخدام غير المتصل «—»، وليس صفراً. هذه لقطة عدادات تنزيل، لا عدد أشخاص. عولج تعثر أول إغلاق لاتصال التصحيح في أداة الاختبار بانتظار محدود؛ أُعيد التشغيل بنجاح.
- الحزم المحلية: NSIS وportable للمشاهد وportable خاص لأدمن. تشغيل MPV من portable ناجح حتى مع تعطيل RAF عمداً. مطابقة 133 ملف core/electron/dist في كل حزمة مشاهد دون اختلاف؛ ASAR متطابق وMPV مطابق vendor، وأدمن غير موجود في المشاهد. مطابقة 12 ملفاً في حزمة أدمن، بما فيها notice-publisher وaccount-server؛ أصلح تضمين اعتماد notice-publisher الذي كان غائباً من إعداد الحزمة القديم.
- نجح فحص معالج NSIS وخيار all-users وهو مفعّل؛ installed:false لأن الاختبار يلغي قبل التثبيت. كشف الفحص أن windowsHide:true يخفي معالج NSIS نفسه ويترك حواراً غير مكتمل؛ أداة الاختبار الآن تظهر نافذتها التفاعلية الخاصة وتنتظر عناصر مرئية، مع الإبقاء على منع الضغط على Install أو اختيار all-users أو الموافقة على UAC. لم يتغير إعداد المثبّت لإرضاء الاختبار.
- حزم المراجعة غير موقعة Authenticode وغير منشورة. التثبيت الفعلي/UAC/التحديث على مستوى الجهاز لم يُنفّذ.
