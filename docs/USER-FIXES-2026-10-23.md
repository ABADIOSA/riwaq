## التحقق

- 904 اختبارات Node ناجحة، صفر فشل/تخطي؛ التنسيق وبناء سطح المكتب والويب ناجحان.
- Chromium كامل: القوائم والزر الأيمن/Shift+F10، السحب، العرض الرئيسي، Ctrl+K العربي، تشغيل الفيديو ومستوى الصوت، المسودات المشفرة، الحسابات والمزامنة، الإحصاءات الاختيارية ضد HTTP/SQLite محليين.
- Windows MPV: الوضع المدمج والمنفصل، الترجمة والصوت، التقديم والسرعة وإعادة التحميل والإيقاف، تعافي HUD المجمد وF8. عينة SDR لا تثبت جودة HDR أو Dolby Vision.
- Windows جلسة رِواق: بيانات إضافة محلية، استبدال الترشيح، طابور المشاهدة، التفضيلات والتراجع وإعادة التحميل، الإعدادات والطي وتطبيع التخطيط السابق.
- فحص صور ويندوز كشف أن الاختبار القديم كان ينقر برمجيًا خلف شاشة الترحيب وعلى عناصر مخفية. يستخدم الآن Playwright على نافذة main تحديدًا، ويتخطى الترحيب من الزر الفعلي ويفتح الإعدادات المتقدمة وإدارة الذوق قبل النقر. النجاح النهائي والصور الحالية بعد هذه الإصلاحات، لا النتائج القديمة المضللة.
- اختبار التقويم القديم ربط نافذة تاريخية بساعة الجهاز فصار يفشل بمرور الأيام؛ ثُبّتت ساعة الاختبار على تاريخ بياناته بدل تغيير التطبيق أو إضعاف التحقق. عُدّلت محددات الاختبارات التي كانت تشير إلى More أو موضع الإعدادات السابق.
